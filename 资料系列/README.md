# 资料系列（附录字母表冻结后的收录通道）

> 2026-09-01 起，附录字母表 **A–Z 已用尽并冻结**——26 本附录的字母、文件名与内部节号（G.x…Z.x）不再变动。此后新增的全文收录文档一律进入本目录，按体裁编号命名。

## 命名规则

| 体裁 | 文件名 | 示例 |
|---|---|---|
| 赛道全景/调研报告 | `全景NN-标题.md` | `全景01-主流XX系统全景.md` |
| 机制详解/上手教程 | `详解NN-标题.md` | `详解01-XX实战指南.md` |
| 整仓源码解剖 | `源码NN-标题.md` | `源码01-XX源码架构解析.md` |

NN 为该体裁内两位递增序号，与附录字母无关。

## 收录流程（与附录同款纪律）

1. **正文转换**：去除文首元信息块与目录；文内节号保持文档自有的普通数字编号（无字母前缀）；文中"第 N 章"若指文档自身章节须改写（如"本文第 3 节"），避免与本书章号混淆；文件名与 H1 不使用"第N章 / 附录X"模式（校验器按该模式识别书稿结构件）。
2. **书稿件**：加定位 blurb（分工、信息基准、来源 [C-xx]）与页脚对照索引。
3. **注册**：book.yml 的 `series:` 段登记（`id: series-<拼音>-NN` / `title` / `path` / `status: draft`）；`references/sources.yaml` 新增 C-xx（`claim_scope: [series-...-NN]`，check_sources 已支持）；附录 C 表格与映射；主 README"资料系列"表加行。
4. **门禁**：纳入 check_render / check_crossrefs / check_mermaid；不受六段结构、图号连续、snippet 门禁约束（同详解扩展版）。常见修复模式见提交历史（GFM 加粗五类失效、mermaid 保留字/引号/花括号空格）。

## 与附录的关系

附录 A–F 是审读态工具书；G–K 详解上手、L–V 赛道地图、W–Z 源码解剖是 2026-08 冻结前收录的资料层。本目录是资料层的**延续**，只是编址方式从字母换成体裁编号——定位、纪律与门禁待遇完全一致。各附录分工列表（"A 讲机制……Z 解析 OpenCode 源码"）随字母表一同冻结，不再为系列条目扩行；系列内容以本 README 与主 README 的系列表为索引。
